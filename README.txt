ALPHA CARE MEDICAL CENTRE — Lakkidi
Clinic management app adapted from the supplied HealBay beta project.

Included updates:
- Alpha Care clinic logo and branding.
- Clinic name and address in prescription and invoice headers; doctor name removed from headers and prescription signature block.
- Reusable saved Chief Complaints and Assessment/Diagnosis text.
- A4 portrait prescription printing.
- A5 portrait bill / invoice printing.
- Separate bill categories: Consultation fee, Medicine fee, Procedure fee, Observation fee, House call fee, Other fee.
- Existing patient, consultation, appointment, billing, reports, medication/lab presets and encrypted local backup workflows retained.

SETUP
1. Extract all files together.
2. Host on an HTTPS static site (or open in a supported local environment with Web Crypto and IndexedDB).
3. On first launch, create a strong passphrase of at least 12 characters.
4. In Settings, confirm the clinic address. Default is “Lakkidi, Kerala”; edit it to the complete postal address before printing.
5. Export encrypted backups regularly and store them separately.

PRINTING
- Prescription: A4 portrait.
- Bill / invoice: A5 portrait.
- In Safari print dialog, select the matching paper size if it is not selected automatically.

IMPORTANT SECURITY NOTE
This is a browser-based offline prototype adapted from the supplied beta. It has not undergone independent security, privacy, clinical workflow, or regulatory validation. Do not enter real identifiable patient information until it has been professionally reviewed and approved. Data is stored in this browser's encrypted local vault; clearing browser data can permanently erase the vault. Test backups and recovery using fictional data first.
